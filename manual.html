01 · Start here

Landing page → Kim 2010

HEGEMON means Hierarchical Exploration of Gene Expression Microarrays Online. It lets you inspect processed expression measurements, find gene relationships, define sample populations and compare their expression or survival. These analyses support research hypotheses; they do not establish causation or provide patient-specific clinical advice.

This is the portable, offline manual. Screenshots and example downloads are included. Open your running Hegemon website separately to perform the steps.

  1. Open the updated Hegemon website. Under Types of Studies, find Bladder cancer and click View. “Find a study type” filters category names, not genes.
  2. In Select Dataset, choose Kim 2010 bladder cancer Overall (n = 256). Check the registry ID B2.1 in Dataset information; other bladder studies are different datasets.
  3. The source button GSE13507 ↗ opens the study’s GEO page. Source links are generated from the configured source field. Selecting a dataset shows metadata first: an empty scatterplot at this stage is correct.
  4. Keep Gene A = TYROBP and Gene B = FCER1G. Click each Find probes button. Choose ILMN_1778977 for A and ILMN_1785493 for B.
  5. Click Explore expression. You should now see TYROBP on X, FCER1G on Y and 256 paired samples. Keep this default pair for every group and report example unless instructed otherwise.

02 · Left column

The main scientific buttons

Choose Kim first. These tools open in the middle Analysis results tab. Unless stated otherwise, use A = TYROBP and B = FCER1G. These are dataset-level tools: checking a sample group does not turn their scans into a subset analysis.

Top Genes

  1. Expand Analysis settings; leave Number of genes = 10.
  2. Click Top Genes on the left.
  3. Inspect the returned probe IDs and annotations. The legacy ranking uses dynamic range and variability, not simply highest mean expression or a comparison of your groups.
  4. To inspect one, copy its probe ID into a gene field, click Find probes and Explore expression.

Get IDs

  1. Enter TYROBP and FCER1G, then click Get IDs.
  2. Read the matching IDs and gene labels. Expect TYROBP → ILMN_1778977 and FCER1G → ILMN_1785493 for this dataset. Use the main probe selectors for the full annotations.
  3. For a list, enter space-separated symbols such as TYROBP FCER1G. The legacy best matching ID is shown in bold. Select the intended feature; multiple probes can measure different transcripts or regions.

Get Plots

  1. Restore the two default gene inputs; click Get Plots.
  2. A large static plot appears for each resolved A/B probe pair. Putting TYROBP FCER1G in both fields produces four pair combinations, including self-pairs.
  3. Choose PNG, JPG, PDF or SVG in the figure format selector, then Download figure.
  4. Click Use in Explore to load that exact pair in the interactive main scatterplot. Get Plots itself does not provide interactive brushing.

Get Stats

  1. Use the default pair and click Get Stats.
  2. Inspect the interactive figure and the Boolean/correlation statistics below it. Wheel zoom or drag a zoom rectangle; the statistics still describe the full dataset.
  3. For this pair the displayed Pearson correlation is about 0.931. A high positive correlation means co-variation, not proof that one gene regulates the other.
  4. Use Use in Explore before defining populations for this pair. See all figure-card controls.

Explore

Click Explore on the left, or the main Explore expression button, to load the resolved pair into the Scatterplot tab. This is the place for sample rectangles, patient highlights and group creation. Changing text alone does not update a previously loaded plot.

MiDReG

  1. Enter TYROBP in Gene A and empty Gene B. Leave SThr = 3 and PThr = 0.1.
  2. Click MiDReG. The cards count matching probes by Boolean relationship, not unique genes.
  3. Click Low → High. In the captured Kim run it contains 51 probes. Select ILVBL / ILMN_1759419 to reproduce the illustrated pair.
  4. Use Filter matching probes to search this category by symbol/ID. Copy probe IDs copies the currently filtered matches; use Ctrl/Cmd+C on the offered text if the browser disallows clipboard access.
  5. Inspect the interactive pair and its statistics, then use Use in Explore if you want to select samples for it. Restore the default TYROBP/FCER1G pair before continuing the Kim group exercises.

Resolved query probes expands the matched query IDs. Zero-count relationship cards are unavailable. No detected relationship is count-only in this legacy response; it is not an error and does not provide a probe list.

A Boolean implication is a population pattern, not a causal rule. Samples within each threshold’s ±0.5 uncertainty band are excluded from the Boolean quadrant scoring. Zooming does not recalculate the relationship on the visible region.

Correlation

  1. Use A = TYROBP, leave B empty and click Correlation.
  2. Choose a populated coefficient-bin card. Positive coefficients indicate expression rising together; negative coefficients indicate opposite trends.
  3. Filter the matching probes and select one to see its interactive pair/statistics. Copy probe IDs, Resolved query probes, Download figure and Use in Explore work as in MiDReG.
  4. This scans the full dataset. Use right-side Group correlation to restrict the scan to checked populations.

Gene information

  1. Restore the default inputs and click Gene information.
  2. Read the resolved probes’ dynamic range, minimum, mean, StepMiner threshold, maximum and standard deviation.
  3. Use this to inspect expression variability and scale. It is a numerical expression summary, not a gene-function encyclopedia.

Clear / How to use

Clear retains the selected study, restores TYROBP and FCER1G, and removes the current plot, groups and results. Resolve probes if needed, then click Explore expression again. Refresh also returns to an unplotted state and does not restore unsaved groups.

How to use opens this guide in a new tab so the active workspace stays intact. Close the guide tab to return to your analysis.

Samples and Analysis results tabs

  1. Click Reset view, then the Samples tab.
  2. In Find sample, type GSM340537 and check its row. Change the search to GSM340538 and check that row too.
  3. Click Create group from checked rows. Expect a two-member group. Row selections can persist while filtering; the header checkbox checks the currently visible rows.

05 · Right column

Sample groups: create and keep populations

A group is a named set of sample IDs. It is not a new dataset, a new gene or a permanent change to the lab’s files. Checked groups drive point focus and population analyses. An unchecked group is saved in the current page but inactive.

Build the two populations used for reports

  1. Restore the Kim default pair, or click Reset view if it is already loaded.
  2. Under Patient information, choose c invasiveness, then value 1. The legend and plot update interactively. Clicking a legend value is another way to choose it.
  3. Click Save highlighted group. Rename its editable name to Inv1 and press Tab to apply. Expect 103 samples.
  4. Choose invasiveness value 2, save it and rename it Inv2. Expect 62 samples.
  5. Clear the clinical-field selection to see group colors instead of patient-information colors. Check only Inv1 and Inv2.

Checkpoint: two non-overlapping groups, 103 + 62 = 165 unique members; the other 91 samples fade gray. In this Kim file these 165 all have eligible overall-survival records.

“1” and “2” are stored clinical codes. This guide deliberately calls them Inv1/Inv2 rather than assigning clinical meanings that require the original study’s coding documentation. Merely highlighting a field/value does not save a group or change the configured survival endpoint.

Create an inclusive age range

  1. Reset view; choose n AGE in Patient information.
  2. Enter 60:70 in Numeric range (inclusive).
  3. Click Create range group. Expect 67 samples, including the endpoints.
  4. For comparison, 0:200 produces 165, not 256: samples without a numeric age are excluded. Do not interpret missing values as zero.

Union, Intersection, D-AB and D-BA

Use overlapping groups here to see the difference between all four operations. These G1/G2 groups are a separate exercise from Inv1/Inv2.

  1. Reset view. Save c invasiveness = 1 as the first group G1: 103 members.
  2. Save c Grade = 1 as the second group G2: 105 members. Clear the clinical field.
  3. Check only G1 and G2 and click each operation below. Each operation adds a checked result group; uncheck that new group before testing the next operation.

Export, import and migrate groups

  1. Reset view and rebuild the disjoint Inv1 / Inv2 groups from above. Check both.
  2. Click Export checked groups CSV. Save the downloaded file. For these cohorts expect 165 membership rows plus the header.
  3. Click Reset groups, then Import groups CSV and choose that file. With B2.1 still selected, expect Inv1 = 103 and Inv2 = 62 to return, including their names and colors.
  4. To continue in another session/job: open B2.1, load the intended pair, then import the CSV. Keep a copied analysis link alongside it to preserve the exact gene/probe setup.
Download example Inv1 / Inv2 groups CSV

Save before leaving: a browser refresh, Clear, Reset view or a dataset switch discards unsaved groups. CSV imports groups, not expression datasets. A different dataset ID is rejected; unknown sample IDs are skipped. Overlapping groups can repeat a sample in multiple CSV rows. Re-exploring a different pair within B2.1 retains ID membership—it does not reselect points using the new coordinates.

06 · Right column continued

All group tools

Expand All group tools. Load a gene pair first. Disabled controls can mean missing prerequisites rather than a server error. Tool outputs normally appear in the middle Analysis results tab; Show samples opens Samples instead.

Remove checked

  1. Create three temporary groups. Uncheck the one you want to retain.
  2. Click Remove checked. Only the unchecked group remains.
  3. This deletes saved selections, not expression records. Reset groups differs: it removes every group, checked or not.

Numeric rectangle · legacy Rect1

  1. Restore the Kim default pair and reset groups.
  2. Click Numeric rectangle. Enter 10:12,9:11 in its input, then GO.
  3. Expect a new 102-member group: X between 10 and 12, Y between 9 and 11, inclusive.
  4. Check its right-panel checkbox if initially unchecked. Return to Scatterplot to see members outlined. Its legacy color may differ from the first orange brush group.
  5. 10:12, limits only X; ,9:11 limits only Y. These are expression values, not pixels, ages or zoom limits.

Thresholds · legacy Thr

  1. Click Thresholds with the default pair loaded.
  2. The field is Xminimum:Xthreshold:Xmaximum,Yminimum:Ythreshold:Ymaximum. Its Kim defaults round to about 7.2:10.0:13.7,7.2:8.9:12.8.
  3. Click GO to see a diagnostic preview. Change a central threshold, then GO again to move its diagnostic line.
  4. The preview does not overwrite the processed threshold file, change the main plot’s stored thresholds or redefine existing group membership. Use Plot link if shown to open the generated diagnostic image; Image link opens the original pair image.

Survival R script · legacy Scr

  1. Keep only the 102-member Numeric rectangle group checked.
  2. Click Survival R script. Analysis results displays R source code, not a plotted image.
  3. Inspect the surv, status, group, nm and colors vectors: this rectangle has 46 eligible survival records, so its other members do not enter the survival calculation.
  4. To see the curve without running R yourself, choose Population analysis & exports → Kaplan–Meier survival → Run analysis.

One group means no between-group test. All group values can correctly be zero and p <- NA_real_ is intentional. A single cohort still has a survival curve. For two-cohort comparison rebuild Inv1/Inv2. If you run a copied script outside Hegemon, change its temporary PNG filename to a writable path and close the graphics device with dev.off().

Group correlation · Corr

  1. Reset view and rebuild Inv1 = 103 and Inv2 = 62. Check only those groups; clear the clinical field.
  2. Click Group correlation. It compares other probes with the loaded Gene A and Gene B across the 165-member checked union. With no groups checked it uses the full dataset.
  3. The small result scatter plots correlation to X against correlation to Y. Its points are probes, not patients.
  4. Type TYROBP in the result’s search field and click GO to display a matching table row. You can also draw a rectangle on this small plot to list probes in that coefficient region. The table shows ID, corrX, corrY, n1/n2 and Name.
  5. Numeric result links preview a different pairing in the legacy result area. Confirm the IDs you want and load them explicitly with the main gene controls/Explore expression before running population analyses.

Differential expression · Diff

  1. Keep only disjoint Inv1 and Inv2 checked in that order.
  2. Click Differential expression. It compares expression for the first two checked populations.
  3. Inspect the probe-result scatter and its table. Search TYROBP, then click GO, or draw a rectangle to select a result region. Columns include Diff, −log10(p), usable group counts and annotation.
  4. A larger −log10(p) corresponds to a smaller raw comparison p-value; it is not an automatically multiple-testing-adjusted discovery. Inspect group order and the underlying means before interpreting difference direction.

For the comparison exercises use disjoint Inv1/Inv2, not overlapping G1/G2 or a group plus its own union. These are exploratory comparisons; confounding, sample independence and multiple testing need separate scientific assessment.

Search / export samples · Search

  1. Reset groups, then open Search / export samples.
  2. Enter GSM340537 GSM340538 GSM340539 and click Search Group. Expect a saved 3-member group.
  3. Check that group on the right if initially unchecked. Use Show samples or Scatterplot to inspect it.
  4. For a partial match, enter lowercase search GSM34053 and Search Group. This matches sample-ID fragments; read the returned count rather than assuming three.
  5. For threshold populations, enter capitalized Boolean and Search Group. This creates four quadrant groups plus four low/high marginal groups. They overlap: uncheck unwanted ones before any comparison.
  6. For an expression/clinical CSV, check the wanted groups, leave the search field empty and click Search Group. This exports their union with A/B expression and selected patient information; it does not create another search group. If the browser blocks the new tab/download, allow this action for your local site.
07 · Below the workspace

Population analysis & exports

Analyze your populations runs server-side analysis of the checked saved groups. A visual zoom, a typed but unsubmitted gene or an unsaved patient highlight is not its population.

  1. Restore the Kim default pair: TYROBP X / FCER1G Y.
  2. Reset groups and rebuild Inv1 = c invasiveness 1 (103), Inv2 = c invasiveness 2 (62), or import the supplied group CSV.
  3. Check only these two; clear the clinical field. Expand Population analysis & exports.
  4. Choose an Analysis and click Run analysis. Wait for its image before downloading. Changing the dropdown alone does not generate a new figure.

Gene B · violin plot

  1. Choose Gene B · violin plot and Run analysis.
  2. Expect two labeled FCER1G distributions, one for each checked cohort. Width indicates the estimated distribution density; observations and summary marks show the measured values.
  3. Click Download analysis PNG to keep this figure before running another analysis.

Gene B · box plot

  1. Choose Gene B · box plot, then Run analysis.
  2. Compare FCER1G’s median line, quartiles, whiskers and outlying observations across Inv1/Inv2. The figure replaces the previous result.
  3. Download its PNG separately if you want both plot types.

Why only Gene B? How do I plot Gene A?

The four choices preserve the legacy distribution/survival/scatter workflow; the standalone distribution call takes Gene B. Group summaries and the PDF report include both genes. To get a TYROBP violin/box plot: change A to FCER1G and B to TYROBP, Find probes and Explore expression, then run the distribution again. Within the same B2.1 study, saved sample-ID groups remain intact. Do not use Clear or Reset view for this swap; those remove groups.

Kaplan–Meier survival

  1. Choose Kaplan–Meier survival; leave Censor time empty. Click Run analysis.
  2. Expect two overall-survival curves for Inv1/Inv2. Together they contribute 165 eligible observations: 69 events and 96 censored records.
  3. Read the legend and the between-group log-rank comparison. The vertical axis estimates survival probability; follow-up time uses the dataset’s units, months for this Kim setup.
  4. Enter 60 in Censor time and run again. Follow-up beyond 60 months is administratively censored at 60; group membership remains 103/62. 60,120 additionally requests a display maximum of 120. Clear the field to return to the uncensored-by-CT analysis.

Script versus curve: Survival R script exposes the R instructions used for this calculation; Kaplan–Meier → Run analysis executes that workflow and displays an image. Matching groups and CT should give the same underlying analysis. A single checked group has a curve but no two-group p-value. Samples without eligible time/status are omitted.

Normalized survival status = 1 denotes an event and status = 0 censoring. A censored record is not an event; its follow-up ends without an observed event at that time. Do not substitute the raw c overall survival clinical codes (1/2) for the normalized 0/1 status.

Expression scatter · PNG

  1. With Inv1/Inv2 checked, choose Expression scatter · PNG and Run analysis.
  2. Expect a server-rendered scatter for the loaded gene pair with group colors. It uses the expression range, not the browser’s current zoom rectangle.
  3. Click Download analysis PNG. For a saved copy of the exact interactive zoom/highlight view, use the main chart’s Download SVG instead.

Group summaries

  1. Keep Inv1/Inv2 checked and click Group summaries; the analysis dropdown choice does not determine this table.
  2. Inspect group size and A mean, A median, B mean and B median. For the default pair, Inv1 has A mean ≈ 9.326 and B mean ≈ 8.509; Inv2 has A mean ≈ 10.19 and B mean ≈ 9.257.
  3. Use this to check membership and both genes before interpreting a figure. It is a descriptive summary, not the full Boolean statistics table.

Export PDF

  1. Keep the intended pair/groups checked; clear Censor time unless you intentionally want a cutoff.
  2. Click Export PDF and wait for the report download. PDF generation can take longer than an interactive plot.
  3. Inspect the report’s probe labels, cohort labels and counts, expression/threshold information, distributions for both genes and survival material where supported. This is a generated multi-part report, not a screenshot or a PDF version of only the currently displayed PNG.
  4. Save the groups CSV and analysis URL alongside the PDF so you can reconstruct the populations. Re-run/export after changing the setup; an old download does not update itself.

10 · Terminology

Read the labels with confidence

Dataset / study / registry ID
A configured collection of processed measurements and metadata. B2.1 is Hegemon’s ID; GSE13507 is the source GEO accession. A category groups studies, not samples.
Sample / population / cohort
A sample is a measurement column/record. A cohort is a set of sample IDs. Samples are not automatically unique patients; check the original study design for replicates and tissue types.
Gene versus probe
A gene symbol names a biological gene; a probe ID names a measured feature on the platform. One gene can map to several probes with different annotations.
Expression / dynamic range / standard deviation
Expression is the supplied processed measurement. Dynamic range describes its spread; standard deviation summarizes variability around the mean. Values and thresholds are dataset-specific.
Paired samples / missing values
Paired samples have finite measurements on both axes. Missing values cannot form scatter points. A group’s membership count can exceed the count usable by a particular analysis.
StepMiner threshold / low / high
A data-derived split between lower and higher expression. Boolean scoring uses an uncertainty band around the split; low/high is relative to this dataset’s threshold.
Boolean implication
A pattern characterized by one or more unexpectedly sparse low/high expression quadrants. “A low ⇒ B high” does not mean that lowering A experimentally will raise B.
Pearson r
Linear co-variation, from −1 to +1. It does not establish causation and can be affected by outliers or population mixtures.
Union / intersection / difference
Any checked-group member / members shared by all checked groups / membership in one group but not the other groups.
Clinical field prefixes c / n
Legacy categorical / numeric field labels. A code is not self-explanatory; use study metadata to interpret it. Missing values are not a biological category unless explicitly documented that way.
Event / censored / eligible survival record
An event is the configured outcome; censoring ends observed follow-up without that event at that time. Eligibility requires a usable time and normalized status, independently of having expression data.
Kaplan–Meier / log-rank / CT
Survival-curve estimator / comparison across survival groups / optional administrative censor cutoff. One cohort has no between-group comparison; outcome definitions and time units come from the selected study.
P-value versus PThr
A statistical p-value describes a test under its assumptions; it is not the probability that a biological claim is true. The Boolean PThr control instead bounds the legacy error/sparsity score.
SVG / PNG / PDF / CSV
Vector figure / raster image / printable document or scientific report / tabular text. An image is not a restorable group-membership file.
